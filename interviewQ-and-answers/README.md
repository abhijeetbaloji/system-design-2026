## 🔍 Quality & Verification Principles

- **Verbatim Preservation:** Original wording, variable names, code snippets, and constraints are 100% preserved.
- **Atomic Follow-ups:** Multi-part interview scenarios, code examples, error traces, and follow-up prompts are kept unified under single question entries.
- **Unique Identifiers:** Every question receives a globally unique, sequential ID (`Q001` through `Q918`).
- **Deduplication:** Repeated question blocks from different interview transcripts are consolidated into single canonical questions while tracking all source line references.
- **Strict Question-Only Bank:** In accordance with instructions, answers, solutions, and code implementations are strictly omitted for future expansion.
